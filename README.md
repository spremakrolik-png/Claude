## Как открыть прототип

Откройте `prototype/index.html` в браузере, сервер не нужен. Кнопка «Прототип» слева внизу переключает режимы и ведёт по 15 сценариям и состояниям. Состояние (адрес, корзина, вход) хранится в `localStorage`; «Сбросить демо» возвращает к первому визиту.

Брейкпоинты сделаны через container queries, поэтому режим «Мобайл 390» показывает настоящую мобильную вёрстку на десктопе. Все цвета, радиусы и шрифты заданы токенами в `:root`; режим вайрфрейма — это тот же интерфейс на других значениях токенов.
